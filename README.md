# Weatherly — Weather Dashboard

A responsive weather dashboard built with HTML, CSS, and JavaScript. Search for a city to view current conditions and a five-day forecast.

## Features

- Search for cities around the world
- Current temperature and feels-like temperature
- Weather conditions with matching icons
- Humidity, wind speed, and precipitation details
- Five-day forecast with daily high/low temperatures and rain probability
- Optional location-based weather, with a city-search fallback
- Responsive layout for desktop and mobile
- No API key required

## Technologies

- HTML5
- CSS3
- Vanilla JavaScript
- [Open-Meteo Weather API](https://open-meteo.com/)
- [Open-Meteo Geocoding API](https://open-meteo.com/en/docs/geocoding-api)

## Run Locally

1. Download or clone this repository.
2. Open `index.html` in your browser. For best results, use VS Code with the Live Server extension.
3. Allow location access if you want local weather automatically, or search for a city manually.

## Data Attribution

Weather forecasts and geocoding are provided by Open-Meteo. See [Open-Meteo](https://open-meteo.com/) for API details.
